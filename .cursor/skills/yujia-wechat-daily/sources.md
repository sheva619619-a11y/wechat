# 信源与采集配置

## 采集方式

用 Firecrawl MCP 的 `firecrawl_search`（`sources: [{"type":"news"}]` 优先，necessary 时补 web），时间范围近 3–7 天。每天跑 3–5 个查询词即可，不必全跑。

## 查询词库（按栏目）

### 政策速递

- `低空经济 政策 发布`
- `无人驾驶航空器 条例 管理办法`
- `民航局 无人机 新规`
- `低空空域 管理 改革`
- `反无人机 无线电反制 管理办法`

### 安全警示

- `无人机 黑飞 处罚`
- `无人机 机场 净空 事件`
- `无人机 坠落 事故`
- `无人机 偷拍 高压线 事件`

### 技术科普 / 行业观察

- `低空经济 产业 动态`
- `反无人机 技术 侦测 反制`
- `低慢小 探测 雷达`
- `无人机反制 招标`（行业观察用，正文不点名招标方）
- `低空安全 城市 试点`

## 优先信源（可信度从高到低）

1. **官方**：中国政府网、民航局（caac.gov.cn）、工信部、公安部官网及其官方公众号通稿
2. **央媒/行业媒体**：新华社、人民日报、央视新闻、中国民航报、环球时报（技术条线）
3. **垂直媒体**：宇辰网、全球无人机网、低空经济观察类账号
4. **地方官方**：省市政府官网的低空经济方案、试点通知

自媒体爆料、无署名信息**不得作为事实依据**，只能作为选题线索再去找官方源核实。

## 引用规则

- 事实必须写明来源：「据民航局 X 月 X 日消息」「据新华社报道」。
- 政策类必须核对原文生效日期，禁止沿用旧稿日期。
- 事件类只引用已由官方或央媒确认的事实要素（时间、地点、结果），演绎部分明确标注为分析观点。
