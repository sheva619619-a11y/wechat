# 羽嘉低空安全订阅号 · 日更内容

目标：以**可传播的行业深度内容**获量，触达公安/政府/行业读者；靠**软植入**完成天罗工程与猎场一号曝光。  
默认文风双轨：**B 调查叙事（主粮）** / **A 方案建设（每周约 1）**，见 [style-guide.md](style-guide.md)。周配比约 **4B : 1A**。

品牌口径与禁写清单见 [brand-facts.md](brand-facts.md)；信源见 [sources.md](sources.md)；结构排版见 [article-templates.md](article-templates.md)；例文标尺见 [reference-samples.md](reference-samples.md)（含 **低空翼术家** 技术科普任务链写法）。账号包装见工作区 `账号基础包装方案.md`。

## 硬约束（违反即返工）

1. **禁止转载时政类新闻原文**。安全事件只能以「原创评述/分析」角度写，引用事实需注明公开信源。
2. **禁写内容以 brand-facts.md 为准**。
3. **对外数据**须来自口径库或当日核实公开信源。
4. **产出到 `published/{日期}/`**；可用 `push_draft.py` 推草稿箱；**禁止自动群发**。
5. **文风双轨**：默认 B；按 4B:1A 安排 A。禁止卡兹克口语风（除非用户点名）。禁止再交 1200–2000 字「三节摘要稿」。
6. **篇幅硬门槛**：B 正文 3500–4500 字（&lt;3200 不合格）；A 正文 4000–5500 字（&lt;3800 不合格）。
7. 成稿后做**句子层滤镜**：按 style-guide「叠活人感」去洞察路标/翻案句/同义注水（可用 `human-writing` 作滤镜参考，**不替换** B/A 骨架与数字卡排版）；再过 humanizer-zh 去套话（B 保留叙事；A 保留节末金句），最后交卷清单。
8. **配图默认 V2**：封面底图、栏目配套、方法论、A 轨长图一律从 `素材库/` 现行路径取用（已是展陈工程风）。**禁止**从 `archive-赛博风/` 或 `06-A轨架构长图/v1-赛博指挥风/` 取图，除非用户当场点名要赛博风。

## 栏目体系（选题切口）

| 栏目 | 频次建议 | 默认轨 | 植入 |
|------|---------|--------|------|
| 政策速递 | 每周 1–2 | B 为主，纯建设用 A | ≤1 |
| 安全警示 | 每周 1–2 | B | 方法论即可 |
| 技术科普 | 每周 ≤1 | B 或 A | 业内做法口吻 |

### 选题标准（人工与自动化共用）

#### 0. 避重数据源

读 `published/` 近 **10 日**选题简报「今日定稿」。以 main 成稿为准。  
简报含：近 7 日对照表 + **近 7 日 B/A 计数**。

#### 1. 母题标签（7 日内同标签不重复）

| 母题标签 | 涵盖示例 |
|----------|----------|
| `机场净空` | 扰航演练、净空管理办法 |
| `黑飞查处` | 处罚通报、一登二查个案连发 |
| `地方产业政策` | 三年行动、产业对接会通稿 |
| `通航/适航许可` | 通航许可、适航、双轨 |
| `文旅低空事故` | 景区坠落等 |
| `文旅低空场景` | 飞行公园等 |
| `博览会/展会` | 开幕闭幕探展 |
| `技术原理` | 非合作、多源融合 |
| `保险/金融配套` | 低空保险 |
| `公安体系建设` | 纯能力/路径长文（宜 A） |

#### 2. 栏目配额 + 文风轨配额（滚动 7 日）

| 项 | 规则 |
|----|------|
| 政策速递 | ≤2 |
| 安全警示 | ≤2 |
| 行业观察 | ≤3 |
| 技术科普 | ≤1 |
| 案例洞察 | ≤1 |
| **B 调查叙事** | 目标约占 4/5；日常默认 |
| **A 方案建设** | 目标约占 1/5；近 7 日 A=0 且已有 ≥3 篇 B → **今日优先找合格 A** |

#### 3. B 深度门槛（不够则不能荐为 B）

须同时满足：① 可对比的公开事实/数据；② 能剥三层（现象→机制→规则或治理）；③ 信源 ≥2。  
否则改 A、换题，或降级素材池——**禁止硬写浅 B**。

#### 4. 候选评分

| 分项 | 分 | 规则 |
|------|----|------|
| 读者痛点 | 0–30 | 公安/政府/机场相关高分 |
| 时效 | 0–25 | 48h 内最高 |
| 信源等级 | 0–20 | 官方/央媒高 |
| 栏目与轨轮换 | 0–15 | 补缺轨/缺栏目得分高 |
| 可传播性（B） | 0–10 | 反差强、可数字卡 |
| 同构惩罚 | −10～−30 | 与近稿结构过度同构 |

#### 5. 自动化默认行为

- 2–3 候选 → 结合轨配额选推荐 → 直接成稿  
- 案例洞察：近 7 日为 0 且与最高分差 ≤10 → 可优先案例（多为 A）  
- 最高分 &lt;50 或全淘汰 → 降级素材池并标明  
- 简报写明：轨（B/A）、目标字数、分数、淘汰原因  
- 成稿后 **commit + push main**（不开 PR）

### 标题规则

- 14–28 字；禁「震惊」「速看」「疯传」  
- B 优先对比/数字；A 优先路径式（从…到…）  
- 每篇 3 个备选并标推荐
