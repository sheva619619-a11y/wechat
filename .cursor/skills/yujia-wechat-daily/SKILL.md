# 羽嘉低空安全订阅号 · 日更内容

目标：以**行业情报**吸引公安/政府/行业读者，靠**软植入**完成天罗工程与猎场一号的曝光。硬广气息越低越好，单篇植入不超过 1 处。

品牌口径与禁写清单见 [brand-facts.md](brand-facts.md)；信源与采集查询词见 [sources.md](sources.md)；**默认文风**见 [style-guide.md](style-guide.md)；文章结构与排版 HTML 模板见 [article-templates.md](article-templates.md)。账号欢迎语、底部菜单、关键词回复等固定配置见工作区 `f:\1.3\低空安全防护项目\公众号\账号基础包装方案.md`。

## 硬约束（违反即返工）

1. **禁止转载时政类新闻原文**。安全事件只能以「原创评述/分析」角度写，引用事实需注明公开信源；企业公众号无互联网新闻信息服务资质。
2. **禁写内容以 brand-facts.md 的禁写清单为准**：涉军细节、客户内部信息、未公开部署点位一律不写。
3. **所有对外数据必须来自 brand-facts.md 的「可公开口径」或当日核实的公开信源**，不得沿用记忆中的旧数字。
4. **产出到本地草稿，可选推送微信草稿箱**：交付排版 HTML + 建议标题 + 摘要到 `published/{日期}/`。可用工作区 `tools/wechat-draft/push_draft.py` 写入**微信公众平台草稿箱**（订阅号官方 `draft/add` 支持）。**禁止自动群发/自动发布**；推送后仍须用户在公众平台人工复核再点发布。不接入非官方模拟后台发文工具。
5. **默认文风为「政企方案体」**（见 style-guide.md）：导读/导语、一二三结构、节末金句；禁止用卡兹克口语聊天风写羽嘉日更（除非用户临时点名试写）。
6. 成稿后必须过 `humanizer-zh` 风格自查（去 AI 味，但保留方案体结构与节末金句），再过文末检查清单。

## 栏目体系（按周轮换）

| 栏目 | 频次建议 | 角度 | 植入方式 |
|------|---------|------|---------|
| 政策速递 | 每周 1–2 | 新法规/新政策的解读与影响分析 | 结尾一句「合规落地」视角带出平台 |
| 安全警示 | 每周 1–2 | 公开报道的无人机安全事件 → 原创分析成因与防护启示 | 「察控打评」方法论，不点产品名也可 |
| 技术科普 | 每周 1 | 侦测/反制/多源融合等技术原理 | 以「主流做法」口吻介绍自家技术路线 |
| 行业观察 | 每周 1 | 低空经济动态、招投标趋势、大事件盘点 | 通常不植入，纯建立专业形象 |
| 案例洞察 | 每周 ≤1 | 大型活动安保等场景复盘（**一文一案**） | 可正面介绍猎场一号；规划见工作区 `公众号/published/案例洞察-栏目规划.md` |

## 日更工作流

```
Task Progress:
- [ ] 1. 采集：按 sources.md 查询词跑 firecrawl_search（近 3–7 天）
- [ ] 2. 选题：按下方标准挑 1 个主题，向用户报 2–3 个候选（含推荐）
- [ ] 3. 成稿：按 style-guide.md + article-templates.md 写正文（1200–2000 字，政企方案体）
- [ ] 4. 植入：按栏目植入方式加品牌内容，口径对照 brand-facts.md
- [ ] 5. 润色：humanizer-zh 去套话；保留分节与节末金句；标题出 3 个备选
- [ ] 6. 排版：生成内联样式 HTML（模板见 article-templates.md，对齐参考风格样例）
- [ ] 7. 自查：过检查清单后交付到当日目录
```

若用户只要某一步（如「只出选题」「只排版」），直接执行该步。

### 选题标准

优先级：本行业强相关 > 时效（72 小时内）> 与目标读者（公安/政府/园区/机场）痛点相关 > 可安全评述（不涉密、不涉敏感时政）。同题材 7 天内不重复。

### 标题规则

- 14–28 字，禁标题党词（「震惊」「速看」「疯传」）。
- 优先：对比/路径式（「从 A 到 B」）、政策紧迫（「X 月起施行：…」）、能力词串（「看得见、管得住…」）。
- 每篇给 3 个备选并标注推荐。

## 交卷检查清单（必须逐项执行）

- [ ] 无禁写清单内容（对照 brand-facts.md 逐条扫）
- [ ] 事实性表述均有当日信源或口径库出处，事件时间/地点/数字与信源一致
- [ ] 非「案例洞察」栏目的植入 ≤1 处且不出现价格、客户名单
- [ ] 无 AI 高频套话（「总而言之」「不难看出」「赋能」堆砌）；方案体节末金句不算违规
- [ ] 符合政企方案体：有分节、有分点、有节末金句；非用户点名则无卡兹克聊天风
- [ ] 标题不含标题党词；摘要 ≤120 字
- [ ] HTML 为纯内联样式，无 `<script>`、无外链 CSS，图片位置留占位注释
- [ ] 文末含免责声明（模板见 article-templates.md）
