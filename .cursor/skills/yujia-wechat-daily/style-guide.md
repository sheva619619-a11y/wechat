## B · 调查叙事（默认主粮）

### 何时用 B

有反差数据/事件、能剥三层（现象→机制→规则或治理）、公开信源 ≥2。  
栏目常见：安全警示、行业观察、政策速递（热点解读向）。

### 结构（5–7 节）

1. **对比钩子**：一对撞场景或数字（梦想 vs 现实），一句定调  
2. **主事实写透**：含换算、认知误区、关联案例（仅公开口径）  
3. **升一层机制**：如非合作目标、双轨许可、验真、标准碎片化等  
4. **规则/技术回应**：时间线或主流解法（禁写反制参数细节）  
5. **建设启示嵌叙事**：如「管得住＝飞行前评估 + 飞行中冲突防护 + 标准统一」（不要改成六大能力清单体）  
6. **反常识判断**：如「安全不是刹车是油门」  
7. **短句结语** + 信源列表  

可选：文首「深度观察」类标签；**不要**写「本文面向公安…」式导读（留给 A）。

### 语言

| 要 | 不要 |
|----|------|
| 媒体叙事、可引用公开原话 | 每节强制「第一第二第三」汇报腔 |
| 数字换算（每天/每小时） | 只有通稿复述没有机制层 |
| 建设点嵌在故事里 | 硬广打断叙事 |
| 结语短句分行 | 堆砌可上 PPT 金句 |

### 版式要点（学 7000）

- 栏目标签可用「深度观察」或原栏目名  
- **关键数字独立成块**（大号数字 + 一行说明）  
- 分节配图 4–6 张；节与节之间有图或留白  
- **禁止正文 `<h1>`**（标题只在后台/接口）  
- 文末「信息来源与出处」列表  

### 植入

≤1 处，优先文末关于我们之前一句方法论；可不点产品名。

## A · 方案建设（每周约 1 篇）

### 何时用 A

滚动 7 日 B 已较多、或选题本身是体系建设/平台能力/分步路径；读者已是「要立项、要对表」的人。

### 结构（5–7 节，可含能力展开）

1. **导读**：读者对象 + 本文范围  
2. **导语**：场景破题 + 短问句  
3. **为何必须建 / 传统为何失灵**  
4. **建设目标或总体架构**  
5. **核心能力展开（至少 2 个完整小节，禁止一句带过）**  
6. **场景优先 / 分步路径 / 误区提醒（择要）**  
7. **结语**：能力词串收束到闭环  

### 语言与版式

保留政企方案体：灰底导读、竖条导语、「•」分点、节末金句（每节可有，勿每段都喊）。  
植入可在「建平台/建闭环」节 1 处点猎场一号。

### 句模（A 可复用）

- 「对公安机关而言，……已不是……，而是……」  
- 「关键在于从『……』，走向『……』」  
- 「不是没有设备，而是缺少统一平台、统一流程和统一指挥」  
- 「……的核心，不是堆设备，而是建闭环」
