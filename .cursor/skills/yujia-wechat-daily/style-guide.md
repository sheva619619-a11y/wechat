## 一句话

面向公安与城市管理者的**方案/汇报体**：场景破题 → 问题拆解 → 分点能力或路径 → 每节一句可上 PPT 的收束金句。专业、克制、可落地，不聊天、不自嘲、不金句鸡汤。

## 结构（默认）

1. **标题**：对比或路径式，可用「从 A 到 B」「……写入……，……要从『飞得开』走向『管得住』」；字数可略放宽到 28 字内
2. **导读**（可选但推荐）：一句话说清读者对象 + 本文讲什么
3. **导语**：具体场景或政策节点 + 连续短问句加压（2–4 个）
4. **分节**：中文数字「一、二、三…」；小标题常带「为什么 / 建什么 / 意味着什么」
5. **节内**：总述困境或背景 →「第一、第二、第三」分点 → **节末加粗金句**（独立成段）
6. **结语**：把全篇能力词再串一遍，收束到闭环 / 管起来 / 走在前面

## 语言

| 要 | 不要 |
|----|------|
| 第三人称、机关/行业口径 | 「我觉得」「坦率的讲」等博主口吻 |
| 短对立词串（看得见 / 管不住） | 标题党、震惊体 |
| 「第一…第二…第三…」分点 | 无小标题的一口气聊天长文 |
| 节末可摘抄金句 | 每段都喊口号 |
| 实战、闭环、依法依规、重体系轻堆设备 | 编造一线故事、过度反制参数 |

## 句模（可复用）

- 「对公安机关而言，……已不是……，而是……」
- 「关键在于从『……』，走向『……』」
- 「不是没有设备，而是缺少统一平台、统一流程和统一指挥」
- 「……的核心，不是堆设备，而是建闭环」
- 「低空经济越发展，……安全治理越要走在前面」

## 植入

放在「建平台 / 建闭环 / 落地能力」节，一句带过「察 · 控 · 打 · 评」与猎场一号，不打断方案体节奏。非案例洞察栏目仍 ≤1 处。

## HTML 样式要点

- 导读：浅灰底块
- 导语：左侧青蓝竖条 + 浅蓝底
- 分节：中文数字编号 + 下划线装饰
- 节末金句：浅蓝底居中加粗
- 分点：青蓝「•」+ 加粗「第一/第二/第三」
