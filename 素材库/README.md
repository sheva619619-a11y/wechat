# 公众号素材库

统一存放可复用配图，避免日更反复用同一张「大型活动车载」或「威胁四宫格」。

**根目录**：`公众号/素材库/`

## 目录结构

| 目录 | 用途 |
|------|------|
| `00-品牌/` | LOGO（横版 / 透明底） |
| `01-封面底图/` | **无字**底图，按栏目分子目录；日更用脚本叠标题 |
| `02-平台介绍/` | 猎场一号 / 天罗工程 / 关于羽嘉 常青图 |
| `03-栏目配套/` | 政策 / 安全 / 科普 / 行业 正文插图 |
| `04-方法论示意/` | 察控打评等可反复用的方法图 |
| `05-案例实拍/` | 仅索引；实拍仍在各案例目录 |
| `99-提示词/` | 待生成 / 重出的 ModeC 提示词 |

## 规格（硬约定）

| 类型 | 规格 | 说明 |
|------|------|------|
| 封面成品 | **1880×800**（约 2.35:1） | 标题条居中；**默认无角标 LOGO**（案例洞察一律无） |
| 封面底图 | 建议 ≥1920 宽，16:9 亦可 | **禁止自带标题文字**；合成时再写字 |
| 正文插图 | 宽 ≥1200，横图优先 | 中文标签要清晰；禁水印、禁可读竞品名 |
| 配色 | 青蓝 `#2ea6e6` / `#1f8fd6` + 深海军蓝 | 避免紫、奶油风、报纸风 |

## 日更怎么用

1. 选题定栏目后，从 `01-封面底图/{栏目}/` 选一张未用过的底图  
2. 用既有封面合成逻辑（1880×800 + 半透明标题条 + `anchor=mm`）出 `00-封面.png`  
3. 正文图优先从 `03-栏目配套/` 与 `04-方法论示意/` 挑，**同图 7 天内不重复当主图**  
4. 成稿目录只放「本篇拷贝」，素材库保留母版
