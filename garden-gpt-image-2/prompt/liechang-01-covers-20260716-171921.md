## 00 · 封面（2.35:1）

**模板**：`poster-and-campaigns/brand-poster.md` + `banner-hero` 横向比例约束  
**建议尺寸**：2.35:1（例：1880×800 / 1536×653）

```text
生成一张微信公众号封面图，宽高比严格 2.35:1（横向超宽）。

【类型】品牌主海报 / 政企科技产品封面
【品牌】羽嘉科技（YUJIA TECH），行业：城市级低空安全 / 警用低空防务
【调性】极简未来感、深蓝科技风、B2G 专业感；主色 #0A1A2E 深蓝 + #00B4FF 青蓝 + 银白；禁止紫色霓虹、禁止赛博朋克乱闪

【主视觉】夜色中国城市天际线（不要可识别的上海地标专名），天空中央巨大青色雷达扫描圆盘与同心圆；若干小型四旋翼无人机被锁定框追踪；HUD 网格极克制，不抢标题

【文案（必须精确，勿错字）】
- 画面正中大标题：「猎场一号」
- 副标题：警用低空防务智能实战平台
- 左上角品牌区二选一（优先 A）：
  A）留出干净深色空白，不生成任何 logo、不写公司名（方便后期贴真实 logo）
  B）若必须画品牌：六边形盾牌图标，内部上箭头+两侧翼状横条，蓝到绿渐变；右侧英文 YUJIA TECH（全大写），下方中文「羽嘉科技」。严禁写成「驭家科技」或其它错字

【构图】标题居中偏上，雷达在标题后方半透明；城市在下 1/3；四周可有极细 HUD 角标
【约束】slogan 不超过主副两行；字体最多 2 种；不要堆数据面板；不要额外品牌；不要水印；中文清晰可读
【负面】错别字、乱码英文、紫色光晕、卡通、拼贴 moodboard、多海报拼板、低清晰度文字
```

## 01 · 城市低空多机场景

**模板**：`scenes-and-illustrations/concept-scene.md`  
**建议尺寸**：16:9

```text
生成一张电影感概念大场景插画，宽高比 16:9，用作公众号正文配图。

【世界观】近未来中国智慧城市 · 低空经济时代 · 安全监测主题（不是战争、不是军事打击）
【调性】蓝调黄昏/蓝调时刻；青蓝监测光圈；专业、冷静、略带科技感；禁止紫色霓虹狂欢风

【构图】
- 前景：1–2 架清晰的民用四旋翼无人机（物流/巡检外观），带轻微青色探测环
- 中景：城市街道与高楼，车流光轨，远处还有 3–5 架小无人机
- 远景：城市天际线与层云；天空有淡淡同心雷达弧，像覆盖城市的监测网
- 机位：略高俯视，广角，电影级景深

【灯光】天际冷蓝主光 + 城市暖黄窗光对比；空气有薄雾颗粒
【文字】画面不要出现任何中文/英文标题、logo、水印、UI 面板文字（纯场景图）
【约束】不要可识别真实地标名称；不要武器化无人机、不要导弹、不要爆炸；不要人脸特写
【负面】赛博朋克过度霓虹、拼贴、海报排版、文字乱码、恐怖氛围
```

## 02 · 四大平台特点（2×2）

**模板**：`infographics/bento-grid-infographic.md`（收敛为等大 2×2）  
**建议尺寸**：16:9

```text
生成一张暗色科技风模块化信息图，宽高比 16:9。标题：「四大平台特点」。

【画布】深蓝近黑背景 #050810；模块圆角 16–20px；描边青色 #00B4FF；模块间距统一；整体像指挥系统 widget，不是浅色 Apple 浅灰风

【布局】严格 2×2 四个等大卡片，左上 01、右上 02、左下 03、右下 04。顶部居中总标题「四大平台特点」。

【卡片内容（文字必须精确）】

01 兼容主流设备
- 五个横向图标+标签，标签依次只能是：雷达｜无线电侦测｜光电｜无线电反制｜便携反制枪
- 底部短句：存量设备直接纳管，开放接入
- 禁止出现：摄像机、球机、NVR、服务器、手机 等无关标签

02 多源融合识别
- 中心为融合核，四周四个源，标签只能是：雷达｜无线电｜视频｜RID
- 底部短句：时空对齐加权融合，降低误报
- 禁止出现：卡口、数据文档、其它英文缩写（RID 除外）

03 威胁自动定级
- 三个等级：Ⅰ 紧急｜Ⅱ 警示｜Ⅲ 关注（颜色红/琥珀/青或绿）
- 底部短句：智能研判，自动定级，可人工复核

04 公安流程开箱即用
- 四步横向：报备审批 → 态势预警 → 出警反制 → 复盘归档
- 底部短句：按公安业务流程预置，开箱即用
- 禁止写成「接警立案侦查结案」等刑侦通用流程

【约束】除 RID 外尽量不出现英文；中文必须清晰无错字；不要品牌 logo；不要紫色；信息密度适中，不要大段正文
【负面】错别字、模块数量不对、标签串台、浅色办公 PPT 风、拼贴板
```

## 04 · 察·控·打·评闭环

**模板**：`infographics/step-by-step-infographic.md`（暗色科技流程变体）  
**建议尺寸**：16:9

```text
生成一张暗色科技风四步流程信息图，宽高比 16:9。

【总标题】察 · 控 · 打 · 评
【副标题】全流程闭环管理，构建低空安全防护体系
【背景】深蓝 #0A1224 + 细电路纹理；主色青蓝 #00B4FF；禁止紫色

【布局】从左到右四个等高竖栏，栏间青色箭头；底部一条横贯平台条，写「一体化低空安全管理平台」

【四栏精确文案】

1. 察｜侦测发现
- 三项（名称必须一字不差）：
  - 雷达：远距离探测 / 范围发现
  - 无线电：信号监测 / 识别定位
  - 光电/视觉：光电跟踪 / 精确识别
- 严禁写成「射频」；必须写「无线电」

2. 控｜合规管控
- 电子登记
- 合规报备
- 分类处置

3. 打｜分级处置
- 高风险：立即处置
- 较高风险：重点处置
- 中风险：监控处置
- 低风险：常态管理
（用红/橙/黄/绿区分）

4. 评｜评估优化
- 态势复盘
- 数据分析
- 评估优化

【约束】中文清晰；步骤编号明确；图标线面简洁；不要真实客户地名；不要公司 logo；不要多余英文段落
【负面】把「无线电」写成「射频」、错别字、军事爆炸画面、拼贴 moodboard、文字糊成一团
```

## 使用建议

1. 在 ChatGPT 选 GPT Image / DALL·E 类模型，一次只贴一条 prompt。  
2. 00 封面若平台没有 2.35:1，先出 16:9 再按 2.35:1 中心偏上裁切。  
3. 品牌 logo 建议后期用真实 `logo-horizontal.png` 贴上，比模型手写更稳。  
4. 若某张文字仍错，用「局部编辑」只改文字区，并粘贴该条中的精确标签清单。
